# 💰 Finance Tracker

Простое приложение для учёта личных финансов.  
Позволяет добавлять доходы и расходы, просматривать историю транзакций с возможностью перетаскивания и сохранять данные в `localStorage`.

## ✨ Основные возможности

### 📝 Форма добавления транзакции

- Выбор типа: **Доходы / Расходы** (обязательное поле)
- **Категория** – динамический список (разный для доходов и расходов)
- **Сумма** – только цифры, валидация от 0 до 10 000 000
- **Дата** – выбор даты, запрет будущих дат
- **Комментарий** – опционально, с чекбоксом «Добавить комментарий»:
  - если чекбокс активен – поле становится обязательным и ограничено 100 символами
  - если снят – валидаторы очищаются (кастомная директива)
- **Валидация** всех полей с уникальными сообщениями об ошибках
- При успешной отправке – всплывающий алерт, форма сбрасывается

### 📜 История транзакций

- Отображение транзакций в виде плиток
- Каждая плитка показывает категорию, сумму, дату и комментарий (при наведении на иконку)
- **Drag & drop** – изменение порядка транзакций внутри блока
- Удаление транзакции по нажатию на кнопку удаления
- Сортировка транзакций по дате:
  - По умолчанию
  - По возрастанию даты
  - По убыванию даты
- Адаптивность:
  - На больших экранах (шире 850px) размеры плиток зависят от суммы транзакции (чем больше сумма, тем крупнее блок)
  - На маленьких экранах (до 850px) динамические размеры отключаются, сетка автоматически подстраивает количество колонок, чтобы контент всегда оставался читаемым
- Данные сохраняются в `localStorage` и восстанавливаются после перезагрузки

### 💰 Форматирование суммы

- Кастомный пайп transactionSum:
  - Добавляет знак «+» для доходов, «–» для расходов
  - Разбивает целую часть на разряды пробелами
  - Отделяет дробную часть запятой
  - Добавляет символ валюты ₽

## 🛠 Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/Sw1ftFox/finance-tracker.git
cd finance-tracker

# Установите зависимости
npm install

# Запустите приложение
npm start
```
